# 生存段位系统 · TrMenu 前端菜单

`rank_gui.yml` 是给 TrMenu 用的界面配置，覆盖「看段位 / 看算法 / 调设置」三件事，
一共 **16 页**、**321 个图标**（每个加分项单独一个图标）。

- 菜单 ID：`rank_gui`
- 打开方式：`/trmenu open rank_gui`、`/rankgui`，或右键绑定物品「时钟（lore 含“生存段位”）」
- 依赖：**TrMenu**、**PlaceholderAPI**（`player`/`server` 等拓展）、**SRExpansion 1.11.0+**
- 可选：**AdvancedPlayerAttribute**（不装则属性相关内容显示为 0 / 原始变量）

## 页面结构

| 页码 | 页面 | 说明 |
|---|---|---|
| 0 | 主页面 | 个人档案、排行榜、指导、属性图鉴、设置、段位列表、计分规则入口 |
| 1 | 个人设置 / 操作 | 自动升级开关、悬浮字开关、手动升级、返回 |
| 2 | 全段位展示 · 选择 | 常规段位 / 额外段位两个入口 |
| 3 | 常规段位（1–50） | 沿用原 `ai_rank.yml` 的 6×9 布局与材质 |
| 4 | 额外段位（51–100） | 同上，Extra 前缀段位 |
| 5 | 计分算法 · 总览 | 一般类 / 方块 / 生物 / 成就 四个入口 |
| 6 | 一般类加分 | 13 项基础权重，每项一个图标 |
| 7 | 特殊方块加分 | 14 类，每类一个图标（含原木/树皮按后缀生效的说明） |
| 8 | 特殊生物加分 | 43 种，每种一个图标 |
| 9 | 成就分类 | 主世界·故事 / 主世界·冒险 / 主世界·农牧 / 下界 / 末地 |
| 10–15 | 成就明细 | 每页最多 45 个，冒险（47 个）自动拆成两页 |

## 主页面部件

| 槽位 | 图标 | 内容 |
|---|---|---|
| 左上 | `I` 个人档案 | 当前/下一段位、段位分与排名、升级进度、**属性加成**、开关状态 |
| 右上 | `R` 排行榜 | 自己排名 + Top10 名字与分数 |
| 中间 | `T` 指导 | 段位分从哪来、怎么升级 |
| 左中 | `F` 属性图鉴 | 8 个属性的作用说明 + 自己当前数值 |
| 右中 | `C` 计分算法 | 进入算法总览 |
| 左下 | `S` 设置 / 操作 | 进入设置页 |
| 右下 | `A` 段位列表 | 进入段位选择页 |

## 设置页部件

| 图标 | 行为 |
|---|---|
| `X` 自动升级 | 显示 `%srank_autorankup%`，点击执行 `srank autorankup` 并刷新 |
| `Y` 悬浮字 | 显示 `%srank_display%`，点击执行 `srank display` 并刷新 |
| `Z` 手动升级 | 显示下一段位与还差多少分，点击执行 `srank rankup` |
| `K` | 返回主页面 |

## 段位页

- **布局与 `ai_rank.yml` 完全一致**：6 行 × 9 格，前 5 行 45 个段位，最后一行 5 个段位 + 右下角返回。
- 材质沿用原菜单（Dirt → `DIRT`、Nether_Star → `NETHER_STAR` …），保证视觉一致。
- 名称沿用原渐变配色，已转换成 TrMenu 可识别的写法（`<gradient:#A0522D:#F5DEB3>`，不加闭合标签，详见下文「颜色写法」）。
- **奖励介绍**：每个段位额外显示
  - `需要段位分`
  - `升级奖励: N 金币`
  - `属性奖励: 血量上限 +2 / 防御 +1`（配置了 `attributes` 才有）
  - `专属内容: …`（配置了 `extra` 才有，例如最高段位的「恭喜达到最高段位！」）
- 已达成判定沿用原菜单的 `perm *rank.<段位>.achieved`，达成后图标发光并显示 `✔ 已达到`。

## 算法页

- 每一条加分项都是**独立图标**，例如：
  - 一般类：`方块破坏 0.01 分`、`击杀生物 0.07 分` …
  - 方块：`煤矿石 +0.018 /个`、`远古残骸 +0.4 /个` …
  - 生物：`牛 +0.01 /只`、`坚守者 +10 /只` …
  - 成就：`石头时代 +0.5 分`、`孤岛求生 +60 分` …
- 数值直接来自服务器实际配置（`SRExpansion_config_in_server/`），不是写死的说明文字。
- 中文名来源：
  - 一般类 / 方块 / 生物：`wiki.txt` 的表格；
  - 成就：优先用 `advancements.txt`（官方简中语言文件，含**标题 + 简介**），
    该文件里缺的 19 条已按 1.21.11 官方 `zh_cn.json` 补进生成脚本的 `$advOverride` 表，
    因此每条成就都会显示准确译名与一句简介。

## 颜色写法（TrMenu 实测规则）

菜单里的颜色**全部使用传统 `&` 码 + `<gradient:…>`**，规则是：

| 写法 | 说明 |
|---|---|
| `&e` `&7` `&l` | 传统颜色/格式码，正常工作 |
| `<yellow>` `<bold>` `<reset>` | **不生效**，不要用 |
| `<gradient:#A:#B>文字` | 渐变从 A 到 B，**后面不要写 `</gradient>`**，渐变会一直作用到下一个颜色标记 |
| `&r` | 需要中途复位颜色时用这个 |

例如额外段位的名字：

```yaml
name: '&e[<gradient:#FFD700:#FF4500>Extra_&r<gradient:#A0522D:#F5DEB3>Dirt&e]'
```

> 多色标 `{#A>}…{#B<>}…{#C<}` 会被拆成连续的 `<gradient:#A:#B>…<gradient:#B:#C>…`，
> 每段都是两色渐变，衔接处颜色一致，视觉上是连续过渡。


## 安装

1. 把 `rank_gui.yml` 放进服务器的 `plugins/TrMenu/menus/` 目录；
2. `/trmenu reload`（或重开服）；
3. `/trmenu open rank_gui` 试一下；
4. 想改布局/文案：直接改 `rank_gui.yml`（注意它会被重新生成覆盖，见下）。

## 重新生成

菜单是用脚本从配置生成的，改了段位/计分/文案后可以重跑：

```powershell
powershell -ExecutionPolicy Bypass -File Trmenu\tools\generate_gui.ps1
```

输入：

| 文件 | 用途 |
|---|---|
| `src/main/resources/ranks.yml` | 段位名、分数、金币、属性、`extra` |
| `Trmenu/SRExpansion_config_in_server/*.yml` | 一般/方块/生物/成就的实际分值 |
| `wiki.txt` | 中文名（方块、生物、成就） |
| `Trmenu/ai_rank.yml` | 原菜单的段位材质映射 |

输出：`Trmenu/rank_gui.yml`。

> 脚本会校验：每页固定 6 行 × 9 格、布局引用的图标必须存在、材质必须是合法 Material。

## 注意事项

- **属性相关**（`%apa_*%`）需要安装 AdvancedPlayerAttribute，否则会显示原始变量文本。
- 主页面 `I` 图标用了 `head:%player_name%`，需要 PlaceholderAPI 的 `player` 拓展。
- 段位页的「已达到」子图标依赖权限节点 `rank.<段位小写>.achieved`，
  由 SRExpansion 的 `settings.permission` 发放；如果改过节点模板，这里也要同步改。
- 成就页按原版标签页拆分：`story`、`adventure`、`husbandry` 归入主世界，`nether`、`end` 单独成页。
- 菜单本身不含 `Free-Slots` 配置，玩家无法把物品放进菜单（`Hide-Player-Inventory: true`）。
